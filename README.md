# Портфолио: бизнес-аналитика, BI и маркетинговая аналитика

Работаю в бизнес- и маркетинговой аналитике с 2013 года: от конкурентного анализа в DHL Express до стратегической аналитики в промышленном B2B. Превращаю данные в управленческие решения — строю модели оценки рынка, клиентов, продуктов и каналов продаж.

**Инструменты:** SQL · Power BI · Yandex DataLens · Metabase · Excel · DAX · финансовое моделирование

## О кейсах

Здесь собраны рабочие и учебные кейсы — не только результат, но и ход рассуждений: почему выбран тот или иной метод и как я пришёл к выводам. Список неполный и пополняется по мере готовности новых материалов.

> Учебные кейсы построены на открытых/тренировочных датасетах. Кейсы, основанные на реальном опыте работы, используют обобщённые данные — без реальных цифр, названий клиентов и компаний, — чтобы не нарушать конфиденциальность.
